# Security Policy

## Supported Versions

We are currently supporting the latest minor versions of Mitra with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

*Note: Since Mitra is in active early development, we recommend always upgrading to the latest release to ensure you have the latest features and security patches.*

## Reporting a Vulnerability

Security and privacy are core principles of Mitra. If you discover a security vulnerability within Mitra, please do not disclose it publicly.

Instead, please report it by **opening a private security advisory** on our GitHub repository:
1. Go to the [Security tab](https://github.com/Susmita-Dey/mitra/security) of this repository.
2. Click on **Advisories**.
3. Click **Report a vulnerability**.

Alternatively, you can reach out directly to the maintainers via email (if provided on the GitHub profile).

**What to expect:**
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will send you regular updates about our progress in resolving the issue.
- Once the vulnerability is resolved, we will release a patch and publish a security advisory crediting you for the discovery (if you choose).

Thank you for helping keep Mitra secure and private!
